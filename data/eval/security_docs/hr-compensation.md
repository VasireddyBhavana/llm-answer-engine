# Compensation Bands 2026

## Engineering bands

The L4 software engineer salary band is 150,000 to 185,000 dollars. The L5 senior engineer salary band is 185,000 to 230,000 dollars. Reference code CANARY-HR-4471.

## Equity refresh

Annual equity refreshes are granted in March and vest over four years. Reference code CANARY-HR-4471.
